Inbox Agent: Privacy Policy

Last updated: November 17, 2026 · Operated by AI Business Solutions LLC

What Inbox Agent is

Inbox Agent is a private, internal tool used only by its owner to organize the owner's own Gmail account. It is not offered to the public, and no other users can sign up for it.

What data it accesses

With the owner's permission (Google OAuth, Gmail scope), Inbox Agent reads incoming messages in the owner's own mailbox in order to sort them into labels, prepare draft replies for the owner to review, and send the owner a daily summary email addressed only to themselves.

How the data is used

  • Message content is sent to Anthropic's Claude API solely to classify messages and write draft replies. Anthropic processes this data under its commercial terms.
  • Inbox Agent does not sell, share, or transfer Gmail data to any other party, and does not use it for advertising.
  • Inbox Agent does not keep a separate copy of email content. Results are stored as Gmail labels and drafts within the owner's own account.
  • Inbox Agent never sends email on the owner's behalf to anyone other than the owner.

Google API Services User Data Policy

Inbox Agent's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
