Why this page exists Admin endpoints accept the token as a URL parameter, which puts your most powerful credential into browser history, autocomplete, proxy logs — and every screenshot. This page sends it as a request header instead. The token is held in memory only: it is never written to localStorage, never put in a URL, and disappears on refresh.
